# Student-Grade-Calculator
## About 

The Student Grade Calculator is a simple Python project that calculates a student's average grade for four courses and generates a performance report.

## What it does
- Asks for the student's name
- Takes grades for four courses
- Calculates the average
- Shows the performance level
- Prints a garde report
